Redesign Proposals

4 个个人网站改版方案

四套方案共用同一份页面结构与渲染逻辑，只替换样式表。点任意一个方案的「查看方案效果」 进入站点预览，再点右下角的「改版方案」按钮（或按 ← → 方向键）即可实时换肤、当场对比。

这些是设计方案，不是最终配色。选定方向后告诉我，我把它应用到线上站点， 再按你的喜好微调配色与字号。对比页与方案样式表都在 preview/ 目录， 不影响已上线的 terrorschiki.github.io。

方案 A · 深色

终端编辑器

Terminal / Code Editor

把主页做成一个深夜代码编辑器：等宽字体、栏目标题写成 ~/Projects 文件路径、空状态写成 // 注释块、时间轴像 Git 提交历史。

最适合
技术博客、开发者求职；受众以程序员为主时辨识度最高
优点
与你的终端 Logo 高度统一，气质专业、有记忆点
取舍
固定深色，对非技术访客略冷淡；长文阅读体验一般

方案 B · 亮色

温润刊物

Editorial / Paper

当成一本纸质刊物来排版：衬线标题、暖白纸张底色、居中对称版式、发丝分隔线，终端 Logo 换成纯文字签名。

最适合
偏内容型的博客、写长文的人
优点
最耐看、最适合阅读，给人沉稳专业的印象
取舍
视觉冲击力弱于 C，动效克制

方案 C · 亮色

霓虹潮玩

Neo-brutalism / Pop

高饱和撞色 + 粗黑描边 + 硬阴影（不模糊）+ 胶囊标签，把主页做成一张潮流海报。

最适合
做自媒体、视频、设计或前端方向，想让人一眼记住
优点
个性与辨识度最强，和「自媒体视频」栏目气质最搭
取舍
偏潮玩；正式学术或传统求职场景可能显得跳脱

方案 D · 亮色

极简留白

Minimal / Nordic

去掉所有阴影与圆角，用大量留白、发丝线与字距建立秩序：栏目标题左对齐并带 01 / 02 / 03 编号，卡片退化成细分隔线。

最适合
求职作品集、工程师个人页
优点
最通用耐看、加载最轻，全靠内容取胜；信息层级最清晰
取舍
个性表达最弱，偏「安全」
